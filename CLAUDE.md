# SafeWay Project Rules

## Vault Documentation Sync
After every code change, update the relevant `.md` documentation files in the project root (Obsidian vault). Check which `.md` files correspond to the files changed and update them to reflect the new implementation.

## Vault Context Reading
When the user asks about a feature, first read the relevant `.md` files from the Obsidian vault for context before answering or making changes. The vault is the source of truth for feature intent.
